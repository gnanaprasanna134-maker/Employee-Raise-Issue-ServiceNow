# Custom Application

## Application Name

Employee Center

## Description

The Employee Raise Issue project is developed as a custom ServiceNow
application for managing employee IT-related issues.

## Purpose

The application provides a structured process for employees to raise
IT issues through the Employee Center portal.

## Main Components

- Custom Employee Raise Issue table
- UI Policies
- Dependent fields
- Record Producer
- Employee Center portal
- Custom Service Portal widgets
