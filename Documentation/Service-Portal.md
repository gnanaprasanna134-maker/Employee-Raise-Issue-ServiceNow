# Service Portal

## Portal Name

Requesting Portal

## Portal URL Suffix

employee_request

## Homepage

Employee Center Homepage

## Purpose

The Service Portal provides a user-friendly interface through which
employees can access the Employee Raise Issue functionality.

Employees can raise their issues without directly accessing the
backend ServiceNow table.

## Portal Configuration

The portal is configured with:

- Employee Center Homepage
- Employee Center Menu
- Employee Center Coral Theme
- Login Page
- Knowledge Base Home Page

## Custom Page

A custom page is configured within the Employee Center portal to
provide access to the Employee Raise Issue functionality.

The page contains custom widgets that improve the user experience
and provide quick access to the issue submission process.

## Portal Layout

The page uses a two-column layout for displaying the custom widgets.

### Column 1

Commercial Widget

### Column 2

Link Redirect Widget

## User Flow

1. Employee opens the Employee Center portal.
2. Employee navigates to the Employee Raise Issue section.
3. Custom widgets are displayed on the page.
4. Employee interacts with the widgets.
5. Employee selects the Raise Ticket option.
6. The Raise Employee Issue Record Producer opens.
7. Employee submits the issue.

## Benefits

- Provides a simple employee-facing interface.
- Makes issue submission easily accessible.
- Improves the overall user experience.
- Integrates custom widgets with the Record Producer.
- Provides a centralized portal for employee requests.
