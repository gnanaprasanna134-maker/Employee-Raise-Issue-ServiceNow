# Record Producer

## Record Producer Name

Raise Employee Issue

## Target Table

Employee Raise Issue

## Purpose

The Record Producer provides a simple interface for employees to
submit their IT-related issues through the Employee Center portal.

Instead of directly accessing the Employee Raise Issue table,
employees can use the Record Producer to enter the required
information.

## Variables

The Record Producer contains variables to collect employee and
issue-related information.

Examples include:

- Requester
- Category
- Subcategory
- Short Description
- State
- Priority
- Assignment Group

## Issue Creation Process

1. Employee opens the Employee Center portal.
2. Employee selects the Raise Employee Issue option.
3. The Raise Employee Issue Record Producer opens.
4. Employee enters the required issue details.
5. Category and Subcategory are selected based on the issue type.
6. The form validates the required information.
7. Employee submits the request.
8. A new record is created in the Employee Raise Issue table.

## Benefits

- Simplifies issue submission.
- Provides a user-friendly interface.
- Reduces direct access to the backend table.
- Ensures structured issue information.
- Integrates the issue submission process with the Employee Center portal.
