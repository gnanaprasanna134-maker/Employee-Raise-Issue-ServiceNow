# Employee Raise Issue – ServiceNow

## Overview

Employee Raise Issue is a ServiceNow-based application that allows
employees to raise and manage IT-related issues through an Employee Center portal.

## Technologies Used

- ServiceNow
- Custom Application
- Custom Table
- Record Producer
- UI Policies
- Dependent Fields
- Service Portal
- HTML
- CSS
- JavaScript

## Key Features

- Employee issue submission
- Issue category and subcategory selection
- Dependent fields
- Priority management
- Assignment group
- State management
- Record Producer for issue creation
- Custom Service Portal
- Custom Service Portal widgets

## Application Flow

Employee
↓
Employee Center Portal
↓
Raise Employee Issue
↓
Record Producer
↓
Employee Raise Issue Table
↓
Issue Management

## Custom Table

Table: Employee Raise Issue

### Fields

- Number
- Requester
- Category
- Subcategory
- Short Description
- State
- Priority
- Assignment Group

## Custom Widgets

### Commercial Widget
A custom portal widget created using HTML and CSS.

### Link Redirect Widget
A custom widget that redirects the user to the Employee Issue Record Producer.

## Outcome

The application provides a structured way for employees to raise
IT-related issues through a ServiceNow portal.
